## 주요 변경

- **V5 Full Effort 선택**: 생성 파라미터에서 V5 Full의 Medium/High를 고를 수 있습니다. Medium은 14스텝·Euler Ancestral·Heavy UC로 고정되며 사용자·캐릭터·씬 네거티브와 CFG Rescale은 보내지 않습니다. 네거티브 칸에 안내가 표시되고, 메타데이터에도 실제로 보낸 값만 기록됩니다.
- **Linux 지원**: Linux x64 AppImage를 함께 배포합니다. 패키지 안에서 sharp가 정상적으로 로드되도록 고쳤고, Electron과 GLib가 충돌하지 않도록 Linux에서는 sharp WebAssembly 빌드를 사용합니다.
- **테마 대비 개선**: 모든 테마 프리셋에서 본문·보조 글자와 하이라이트가 읽을 수 있는 대비를 갖도록 색상을 토큰으로 정리했습니다. 위험·성공·경고 색은 채움색과 글자색을 분리해 버튼이 바래지 않고, 창 닫기 버튼은 OS 관례대로 빨간색을 씁니다.
- **빈 미리보기 인사말**: 이미지가 없을 때 시간대에 맞는 인사말을 보여 줍니다.
- **성능**: 히스토리·씬·라이브러리 썸네일을 base64 대신 `nais-image` URL로 불러오고, 스트리밍 미리보기가 이미지 그리드 전체를 다시 그리지 않도록 했습니다. 큐는 끝난 항목을 최근 50개만 유지하고 원본 이미지를 브로드캐스트에서 제외합니다. 자주 쓰는 목록 쿼리에 인덱스를 추가했습니다.

## 기존 사용자 데이터

이번 버전은 데이터베이스 스키마를 **v18에서 v20으로** 올립니다(인덱스 추가만, 데이터 변경 없음). 업그레이드 전에 기존 DB가 자동 백업되지만, **v20 DB는 이전 버전 앱에서 열 수 없으니** 1.0.27 이하로 되돌리려면 자동 백업을 복원해야 합니다.

## 다운로드

- Windows x64: `nais3-1.0.28-setup.exe`
- Mac Apple Silicon: `nais3-1.0.28-arm64.dmg`
- Mac Intel: `nais3-1.0.28-x64.dmg`
- Linux x64: `nais3-1.0.28-x86_64.AppImage` (Ubuntu 22.04 이상은 `libfuse2` 필요)

Mac ZIP과 Windows·Linux 업데이트 메타데이터는 앱 내 자동 업데이트에 사용됩니다.

## Highlights

- V5 Full Medium/High effort toggle. Medium fixes 14 steps, Euler Ancestral and the Heavy UC preset, and does not send user, character or scene negatives or CFG Rescale; the UI and saved metadata reflect what is actually sent.
- Linux x64 AppImage builds, with sharp packaged correctly and running on its WebAssembly build under Electron on Linux.
- Readable contrast across every theme preset, with separate fill and text colors for status colors and an OS-style red window close button.
- A time-of-day greeting on the empty preview.
- Faster lists and generation: thumbnails served over `nais-image` URLs, streaming previews kept out of grid re-renders, a lighter generation queue, and new database indexes.

Database schema moves from **v18 to v20** (indexes only). The previous database is backed up automatically before upgrading, but **a v20 database cannot be opened by older versions**; restore the automatic backup to downgrade.
